# Tempad to Map: Xaero's edition

Shows your Tempad teleport locations as Xaero's Minimap waypoints.

Tempad locations are synced from the server to each player, so the mod works
in single-player, LAN, and dedicated-server worlds. Additions, edits, and
deletions in Tempad are reflected in Xaero's Minimap.

## Requirements

- Minecraft 1.21.1 with NeoForge 21.1.x
- [Tempad](https://modrinth.com/mod/tempad) 3.x on both sides
- [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap) on the client to display waypoints

Xaero's Minimap is optional for loading the mod. Waypoints appear only for
the current dimension; locations in other dimensions are applied when the
player enters them.
